# Project profile for Lean Squad

Copy only when preparing a reusable workflow. Fill applicable fields from current
project rules and user authorization; omit unused fields. This profile records
requirements and permissions but does not grant or enforce them.

| Setting | Project value |
| --- | --- |
| Objective and scope | Active task, acceptance gap, result consumer and exclusions. |
| Checkpoint | Persistent path, current base and next ready action. |
| Ownership | Owned paths, shared files, dependencies and invariants. |
| Validation and review | Required commands, acceptance criteria and review gates. |
| Delegation | Existing authorization, supported model/effort constraints, observed capacity and handoff if required review is unavailable. |
| External actions | Existing commit, push and external-action authorization. |
| Evidence | Source revisions, artifacts, covered behavior and unresolved gaps. |
| Optional allowance budget | Authorized unit/amount, lead identity and persistent budget file. Follow the skill's allowance procedure. |
| Optional audit | Exact root log, session directory, dated rate source and unknown model/rate mappings. |

Handoff: objective, base, owned paths, dependencies, checks and results, blockers,
next action and result consumer. Include routing and review ownership when used.

Measurement: accepted scope, actual models, unique token totals, typical input
size, dated cost estimate, elapsed time, corrections, validation and evidence gaps.
Keep account allowance and process waits separate from token cost and agent waits.
